The museum label a museum in the year 3000 puts beside an ordinary object from today: a parking meter.

> Parking meter, c. 2026: humans inserted coins into this box to rent ten minutes of a patch of ground they did not own.

One line, 118 characters. The label reads as dry curatorial copy and lands its punch in the final clause — humans paid to rent a patch of ground they did not own. A reader who has never seen a parking meter in use still gets the joke, because the label explains the object while exposing it.

Run it with `python3 main.py`; it prints the label and writes it to `/output/entry.txt`.
